# GOOBA Software House — Digital Flagship Website

The official digital flagship web application for **GOOBA (Software House)**, engineered with React 19, Vite, and Tailwind CSS v4.

---

## 🏛️ Editorial Architecture & Design Adaptation

This flagship adapts the editorial asymmetry, disciplined negative space, and architectural tension from classical editorial layouts, reimagined for elite software engineering:

1. **The Asymmetric Hero Swap:**
   - The GOOBA 3D Faceted Gemstone artifact (`/GEM.png`) is positioned on the **LEFT** as the primary sculptural focal point, complete with interactive 3D perspective tilt and burgundy glow caustics.
   - The **RIGHT** balances with stark, geometric Century Gothic typography, sub-millisecond telemetry status, and asymmetric whitespace.
2. **Editorial Framework:**
   - 1px hairline architectural boundaries (`#292929`/20 and `#8C2545`).
   - Fixed right-margin metadata with vertical coordinates (`29.9792° N, 31.1342° E`), system versioning (`SYS.V2`), and vertical interactive triggers.
   - Bottom editorial tickers (`COPYRIGHT © 2024–2026 GOOBA INC.` • `SYSTEMS • ARCHITECTURE • AUTOMATION • AI ENGINES`).

## 🔤 Exact Typography Hierarchy

- **Logo Wordmark (`GOOBA.`):** Century Gothic / Montserrat geometric uppercase, wide letter spacing.
- **Logo Descriptor (`SOFTWARE HOUSE`):** Clean, neo-grotesque sub-descriptor.
- **Display Headings:** Century Gothic / Futura geometric display.
- **Body & UI Text:** Clean system sans-serif / Inter.
- **Technical Metadata / Numbers:** Space Mono (`[SYS.ARCH.01]`, `[01/06]`, latency budgets).
- **Editorial Pull Quotes:** High-contrast serif (`Playfair Display`) for the core brand manifesto.

---

## 🚀 Sections & Systems

1. **Header & Navigation:** Minimalist bar with wordmark, links, live status indicator (`SYS.OK [99.99%]`), and mobile drawer.
2. **Hero:** 3D Gemstone on the left, Century Gothic headline *"Digital infrastructure for organizations that are ready to scale"*, live terminal telemetry console, and ticker strip.
3. **Systems & Capabilities Matrix:** 6 architectural systems (`SYS.01` to `SYS.06`) with strict 0–2px radii borders and deep specification inspector modals.
4. **Case Studies:** Highlighting **GOOBA MUN Sites** (*"What used to take 5 weeks can now be done in 5 minutes"*), featuring a live parliamentary voting simulator, before/after metrics, and Aether Cargo Freight / Kromatik Ledger studies.
5. **Brand Philosophy:** High-contrast Playfair Display pull quote with the three non-negotiable architectural tenets.
6. **Executive FAQ:** Expandable accordion with monospace numbering (`01`, `02`, `03`...), search filtering, and clear technical answers.
7. **Contact Modal:** Direct architectural intake protocol with scope selectors and transmission confirmation.
8. **Footer:** Real-time global clocks (London, Zurich, New York, Cairo, Tokyo), system index, compliance badges, and back-to-top control.

---

## ♿ Accessibility & Performance Standards

- **WCAG 2.1 AA Compliance:** High contrast ratios across `#EAEAE4` ivory and `#3D0617` burgundy surfaces.
- **Keyboard Navigation:** Explicit focus rings, ARIA roles, landmarks (`banner`, `main`, `contentinfo`), and escape-key handling for modals.
- **Performance:** Native Vite bundling, sub-second cold loads, responsive picture formats, and strict layout stability (`CLS = 0`).
